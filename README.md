# The Long Roast: Lawmakers and the File They Cannot Convert

Entry for the make.fun bounty of the same name: one satirical sentence,
at most 320 characters, roasting lawmakers who would regulate AI, crypto
or the internet but cannot convert a file to PDF.

`main.py` (Python 3.13, standard library only) writes the sentence to
`/output/entry.txt`. Run it with `python3 main.py`.
